1. FIX QUIZ ANSWER STRUCTURE
==================================================

Current audit finding:

PracticeQuestion currently stores:
- options: string[]
- answerIndex: number

The lesson authoring data is heavily biased:
- 211 questions use answerIndex 0
- 7 use answerIndex 1
- 1 uses answerIndex 2

This causes the correct answer to appear as the first option most of the time.

Refactor the quiz question model so correctness is based on stable answer identity, not displayed array position.

Use a structure conceptually like:

answers: [
  { id: "...", text: "...", isCorrect: false },
  { id: "...", text: "...", isCorrect: true }
]

or an equivalent clean typed approach.

The UI should render shuffled answer choices.

The correct answer must remain correct after shuffling.

Do NOT grade by:
- displayed index
- first item
- A/B/C/D position

Grade by stable answer identity / isCorrect.

2. SHUFFLE ANSWERS SAFELY
==================================================

Shuffle the choices for each question when the question is initialized/rendered.

- correct answers should naturally appear in different positions

- feedback must still show Correct / Incorrect accurately

Use a proper local shuffle implementation.
